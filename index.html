Services

What we do

We design and build web products, and can service a range of different requirements, from a full build to a single stage. Most projects start with discovery and continue as a monthly retainer.

01

Product discovery

A two-week phase to define the product: user research, user flows, scope, and a build plan with a cost estimate.

02

UI and UX design

Interface design, interface copy, and a design system for developers to build against. Designed using your real data.

03

Ruby on Rails builds

New applications on the current version of Rails, using Hotwire for the front end, with a deploy pipeline your team can operate independently.

04

Rails rescue and upgrades

Upgrades from unsupported Rails versions, dependency updates, test suite repair, and query performance fixes on existing applications.

05

WordPress and Elementor builds and rescue

New WordPress sites with custom blocks or Elementor, and repair of existing installs: updates, security hardening, and editorial workflow fixes.

06

Maintenance and retainers

A fixed monthly allocation covering security and dependency updates, monitoring, bug fixes, and small feature work.

07

Other stacks

Django and Shopify projects, offered on the same terms: builds, maintenance, and retainers.

How we work

Our process

01

Discover

We start with understanding your context, needs and constraints. Based on your vision for the project, we put together a proposal that details the scope of work.

02

Design

We design the screens and flows for the product, and share them with you as we go. This covers the interface, the content in it, and a design system for development.

03

Build

We build the product in weekly cycles, deploying working software to staging each week and to real users once it is ready.

04

Maintain

We continue supporting the product on a monthly retainer: updates, monitoring, bug fixes, and small feature work.
